# 開発者モードの使いかた

中身（シーン・会話・ナゾ・アイテム・エフェクト）を足すための道具箱です。
はじめて触る人が、**実際に手を動かしながら一周できる**ように書いてあります。

- ゲーム上の概念（エリア・シーン・出口）は [`DEVELOPMENT.md`](DEVELOPMENT.md)
- 遊びかたは [`../README.md`](../README.md)

---

## 0. 入る・出る

まず開発サーバーを立ちあげます。

```bash
bun run dev      # http://localhost:3000
```

開発者モードに入る道は三つ。どれでも同じです。

| やりかた | 使いどころ |
| --- | --- |
| メインメニュー（右上 🧳）→ **開発** | いちばん分かりやすい。入っていると緑に灯る |
| `Ctrl` + `Shift` + `D` | 遊びながらさっと出入りする |
| URL に `?dev=1` | 最初から開いた状態で始めたい |

入ると、**窓の右下に `DEV` のバッジ**が出ます。押すと引き出しが開きます。
引き出しを開けているあいだ、ゲーム画面は自動で左へ寄るので、
**中身を見ながら書けます**。

出るときは引き出しの右上「✕」か、もう一度 `Ctrl + Shift + D`。
出ると、下で説明する「座標をひろう」なども一緒に片づきます。

---

## 1. まず「検査」を開いたままにする

引き出しのいちばん左のタブです。**中身を足すあいだ、ここは開けっぱなしで構いません。**

- 上半分 … id のつながりの検査結果。何も無ければ「問題なし」
- 下半分 … いま何がいくつあるか（エリア・シーン・出口・会話・ナゾ・アイテム）

id を書きまちがえると、**画面が黙って壊れるかわりに、ここに理由が並びます。**
たとえば `areaId` を打ちまちがえると、こう出ます。

```
シーン scn_inn_desk（まんげつ亭の帳場）: エリア inn2 が無い
```

同じものはブラウザのコンソールにも出ます（起動時に一度）。

---

## 2. 一周やってみる — 部屋に「調べどころ」を足す

いちばん短くて、道具をひととおり使う練習です。
**まんげつ亭の帳場に、調べると文が出る「窓辺」を足します。**

### 2-1. その場所まで飛ぶ

「**中身へ飛ぶ**」タブを開きます。エリアごとにシーンが入れ子で並んでいます。

```
まんげつ亭  inn
  まんげつ亭の食堂   scn_inn_hall     street ／ 入口 ／ 人 2 ／ ナゾ 2 …
  まんげつ亭の帳場   scn_inn_desk     view ／ 調べどころ 4 …
```

`scn_inn_desk` の行の「**飛ぶ**」を押します。歩かずにその場へ移ります。

> エリアがまだ開いていなくても飛べます。開放そのものを試したいときは、
> 同じタブの「エリアの開放」でチップを押して切りかえます。

### 2-2. 置きたい場所の座標をひろう

「**配置**」タブを開き、**座標をひろう**にチェックを入れます。
ついでに**置き場所を見せる**も入れておくと、いま置いてあるものに目じるしが出ます。

引き出しは `DEV` バッジで畳めます。畳んだまま、
**窓辺にしたいあたり（絵の右上のほう）をクリック**します。

もう一度引き出しを開くと、拾った座標が出ています。

```
x 0.780 ／ y 0.240      scn_inn_desk
```

### 2-3. 貼れる一行を写す

拾った座標の下に、種類のチップが並んでいます。
**調べどころ**を押すと、そのまま貼れる形になります。

```
{ id: 'prp_desk_5', name: '???', text: '???',
  x: 0.78, y: 0.24, w: 0.16, h: 0.2 },
```

`???` を埋めて、`src/data/scenes.ts` の `scn_inn_desk` の `props` に足します。

```ts
{
  id: 'prp_desk_window',
  name: { ja: '窓辺', en: 'By the Window' },
  text: {
    ja: '磨りガラスの向こうに、時計塔の影がぼんやりと見える。桟に指を這わせると、埃がついた。',
    en: 'Beyond the frosted glass, the clocktower is a soft shadow. Dust comes away on a finger.',
  },
  x: 0.78,
  y: 0.24,
  w: 0.12,
  h: 0.16,
},
```

保存すると、そのまま画面に反映されます（`bun run dev` はホットリロードします）。

### 2-4. 確かめる

1. 画面に光る点が増えているはずです。押すとポップアップが出ます
2. 「**検査**」タブに戻って「問題なし」のままか見ます
3. わざと `x: 1.4` にしてみると、こう出ます

```
scn_inn_desk/prp_desk_window: x が 0〜1 の外
```

直したら消えます。これが基本の一周です。

## 3. タブごとの使いどころ

### 検査

中身のつながりを通しで見ます。見ているのは、たとえば次のようなこと。

- 実在しない id への参照、id の重複
- 出口の戻り道が無い／たどり着けないシーンがある
- 同じエリアの中でシーン名が重なっている
- 会話の分かれ道の飛び先が無い、来る道の無い節がある
- どこにも置いていないナゾ・アイテム・会話

### 中身へ飛ぶ

- **シーン** … エリアごとの入れ子。「飛ぶ」でその場へ
- **エリアの開放** … チップを押して開け閉め。地図の見えかたを試すとき
- **会話** … 「読む」で頭から再生。「読了／未読」で状態だけ切りかえ
- **ナゾ** … 「開く」で直接挑戦。「正解／未解」で状態だけ切りかえ

書いた会話をその場で読み返せるので、**文章を直しては読む**を繰り返せます。

### 配置

いちばん時間を節約する道具です。

| 切りかえ | すること |
| --- | --- |
| 座標をひろう | シーンをクリックすると、その位置を 0〜1 で読みとる |
| 置き場所を見せる | いま置いてあるものに、目じるしと座標を出す（人・ナゾ・キラキラ・調べどころ・出口） |

拾った座標は、種類を選ぶとそのまま貼れる一行になります。

```
{ id: 'skl_plaza_manhole_3', itemId: '???', x: 0.31, y: 0.62 },
```

**シーンの種類で出る形が変わります。**
見わたす（`street`）シーンでは、人とナゾは道の上に立つので `y` が付きません。
一枚絵（`view` / `closeup`）では `x` と `y` の両方が付きます。

### ひな型

書き始めの骨組みを写せます。会話・ナゾ・アイテム・登場人物・シーン・エリア・
フラグ・実績・背景画像・エフェクトの十種類。
`???` を埋めて、上の「検査」で確かめる、という流れです。

### 状態

進行の途中からしか出ない画面を確かめるための欄です。

- コイン・ピカラット・プレイ時間を直接書きかえる
- **すべて開く** … 全部の会話とナゾとアイテムを済ませた状態にする
- **初期状態に戻す** … 最初から
- **JSON の出し入れ** … いまの状態を写して、手で直して流しこむ

> ここでの書きかえは、遊びの筋道を通しません。
> 遊ぶ人向けの書きだし・読みこみは、メインメニューの「バックアップ」のほうです。

### フラグ

**「いま何が済んでいるか」を一覧で見る欄**です。実績の解放もここから試せます。

上半分がフラグ、下半分が実績。フラグは仲間ごと（本筋・探索・収集・やりこみ）に
並んでいて、行の頭の丸で立っているかどうかが分かります。

```
● 三十分の空白を知った   fl_alibi        まんげつ亭の本筋を読み終えた
○ 水車小屋を調べつくした fl_mill_searched 水車小屋の中の調べどころを三つとも見た
```

**「条件」を押すと、何が足りないのかが並びます。**

```
✓ 調べどころ prp_mill_wheel を調査
✓ 調べどころ prp_mill_sacks を調査
— 調べどころ prp_mill_coat を調査     ← これだけ残っている
```

**「満たす」を押すと、その条件を満たした状態になります。**
旗そのものを立てるのではなく、**条件になっている中身のほう**
（会話の読了・ナゾの正解・調べどころ・拾いもの）を満たします。
遊んだ結果と同じ形の状態しか作らないので、
「ここでは出るのに、実際に遊ぶと出ない」ということが起きません。
もう一度押すと「取り消す」に変わり、元に戻せます。

実績のほうは、行の右の「未解放／解放」で **条件のフラグをまとめて** 満たせます。
解放した瞬間、画面の中央上部に知らせが出ます。

| ボタン | すること |
| --- | --- |
| 条件 | そのフラグの条件を、満たしたぶんだけ ✓ を付けて並べる |
| 満たす／取り消す | 条件になっている中身を、まとめて満たす／戻す |
| 知らせをもう一度出す | 「もう見せた」という覚えを消す。条件を満たしているぶんが出なおす |
| いまの旗を写す | 全フラグの立ち／未立ちを一覧のテキストで写す |

> フラグの値はセーブに入っていません。**いつでも進行状況から引き直します。**
> だから「旗だけ立っていて中身が伴わない」という状態は作れません。
> 定義は `src/data/flags.ts`、実績は `src/data/achievements.ts`。

### エフェクト

どの差しこみ口（slot）に何が入っているかを見て、一つずつ入り切りします。
空いている口も出るので、**どこに足せるか**が分かります。
ここでの入り切りはその場かぎりで、読みこみなおすと既定に戻ります。

## 4. よく使う流れ

**会話を書きかえる**

1. `src/data/scenarios/<エリア>.ts` を直す
2. 「中身へ飛ぶ」→ その会話の「読む」
3. 直しては読む、を繰り返す

**分かれ道を試す**

1. 「中身へ飛ぶ」でその会話を「未読」に戻す
2. 「読む」で頭から
3. 別の選択肢を選びたければ、また「未読」に戻す

**新しいシーンを足す**

1. 「ひな型」→ シーン を写す
2. `src/data/scenes.ts` に貼って `???` を埋める
3. **つなぎ元と、新しいシーンの両方に出口を書く**（片道だと検査ではじかれます）
4. 「検査」で確かめてから「中身へ飛ぶ」で見に行く
5. 「配置」で中身を並べる

**遊びの終盤を確かめる**

1. 「状態」→ すべて開く
2. 見たい画面へ飛ぶ
3. 済んだら「初期状態に戻す」

**実績の知らせを見る**

1. 「フラグ」→ その実績の行の「未解放」を押す
2. 引き出しを畳むと、画面の中央上部に知らせが出ている
3. もう一度見たければ「知らせをもう一度出す」

**エリアをまるごと足す**

順番に意味があるので、[DEVELOPMENT.md の 4 章](DEVELOPMENT.md)（実例：水車小屋）
を上から追ってください。この欄の道具は、そのうち 4-7（座標）と 4-12（確かめる）で使います。

## 5. 気をつけること

- **開発者モードは製品のバンドルにも入っています。** 出入りの合図を知らないと
  出てこないだけです。外に出す前に隠したいときは、`App.tsx` の
  `<DevTools />` を外してください
- 「状態」の書きかえは即座に**自動保存**されます。試したあとは
  「初期状態に戻す」か、バックアップから戻してください
- 引き出しの中身は日本語のままです（遊びの側だけが言語設定に従います）
