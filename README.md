# クッキーとクロードの謎解き事件簿

レイトン風のシナリオアドベンチャーアプリ。
携帯ゲーム機の画面に見立てた枠の中で、町を歩き、会話を読み進めてナゾを解いていく。

- **ランタイム**: Bun
- **言語**: TypeScript
- **フレームワーク**: React 19
- **CSS**: 素の CSS（フレームワーク・プリプロセッサなし）
- **画像素材**: なし。背景・立ち絵・マップはすべてインライン SVG で描画

## うごかす

```bash
bun install
bun run dev      # http://localhost:3000 でホットリロード付き起動
```

その他のコマンド:

```bash
bun run start      # ホットリロードなしで起動
bun run build      # dist/ に本番用バンドルを出力
bun run typecheck  # tsc --noEmit で型チェック
```

## 画面構成

| 画面 | ファイル | 説明 |
| --- | --- | --- |
| メイン画面 | `src/screens/MainScreen.tsx` | 町のマップ。行き先ピンを選んで会話へ進む |
| シナリオ会話画面 | `src/screens/ScenarioScreen.tsx` | 立ち絵つきの会話。日本語＋英字幕 |
| メニュー画面 | `src/screens/MenuScreen.tsx` | とけたナゾ・ひらめきしすう・プレイじかん等のステータス |
| メインメニュー | `src/screens/MainMenuScreen.tsx` | トランク型の道具ばこ |

### 画面の行き来

```
        ┌──────────────── メイン画面 ────────────────┐
        │  行き先ピン → 「ここへ 行く」               │
        │       ↓                                    │
        │  シナリオ会話画面 ──(読了/スキップ)──→ 戻る │
        │                                            │
        │  右上ボタン ⚙  → メニュー画面               │
        │  右下ボタン 🧳 → メインメニュー             │
        └────────────────────────────────────────────┘

メニュー画面      ↰ もどる → メイン画面 ／ ⚙ → メインメニュー
メインメニュー    ↰ もどる・とじる → 直前の画面 ／ ⚙ → メニュー画面
```

メイン画面の右上・右下のボタンは、写真3枚目の指定どおりの配置。

### メインメニューの中身

- **ちょうさメモ** — 会話で手に入れた手がかりの一覧
- **ふかまるナゾ** — あらすじと進行度
- **ナゾじてん** — 全 5 話の一覧（未読は伏せ字）
- **セーブ** — `localStorage` に保存
- **？？？ ×3** — 未開放スロット
- **メモ** — 自由記入のメモ帳
- **チャーム** — 集めたお守り
- **とじる** — 直前の画面へ戻る

## 操作

| 操作 | 結果 |
| --- | --- |
| 画面クリック / `Space` / `Enter` | 会話を進める（表示途中なら全文表示） |
| `Esc` | 会話を中断してメイン画面へ |

## ものがたり

メープル町に届いた差出人のない手紙 ——
「まちの時計が十三回鳴る夜、まちの宝が消える」。
探偵クロードと助手クッキーが、5 つの場所をめぐって町のナゾを解き明かす。

場所を 1 つ読み終えるごとに次の行き先が開放され、ひらめきしすう（ピカラット）と
ひらめきコインが手に入る。全 5 話・合計 180 ピカラット。

## ディレクトリ

```
src/
├── index.html            エントリ HTML
├── main.tsx              React のマウント
├── App.tsx               画面のルーティングと進行状態
├── types.ts              型定義
├── data/
│   ├── characters.ts     登場人物（色・帽子の指定）
│   ├── scenarios.ts      シナリオ本文（全 5 話）
│   └── places.ts         マップ上の場所
├── screens/              4 つの画面
├── components/
│   ├── Background.tsx    会話画面の背景（SVG）
│   ├── CharacterSprite.tsx  立ち絵（SVG）
│   └── TownMap.tsx       マップと行き先ピン
├── state/gameState.ts    進行状況の計算とセーブ／ロード
└── styles/               画面ごとの CSS
```

## シナリオを足す

1. `src/data/scenarios.ts` に `Scenario` を追加する
   （`lines` に会話、`reward` にピカラットとコイン、`unlocks` に開放する場所の id）
2. `src/data/places.ts` にマップ上の場所を追加し、`scenarioId` で結びつける

`note` / `charm` を書いておくと、読了時にちょうさメモ・チャームへ自動的に加わる。
