# クッキーとクロードのナゾ解き事件簿

レイトン風のシナリオアドベンチャーアプリ。
街並みを見渡し、人物に話しかけ、道端に置かれた時計でナゾを解き、光る品を拾い集めていく。
地点の移動は、右下の「靴」アイコンから隣へ歩くか、左上の「地図」アイコンで飛ぶ。

- **ランタイム**: Bun
- **言語**: TypeScript
- **フレームワーク**: React 19
- **CSS**: 素の CSS（フレームワーク・プリプロセッサなし）
- **画像素材**: なし。背景・立ち絵・マップ・ナゾの図はすべてインライン SVG で描画
- **音声素材**: なし。BGM・効果音は Web Audio API でその場で合成
- **エフェクト**: canvas に手続きで描画。差しこみ口を各画面に用意（`src/effects/`）
- **開発者モード**: 中身を足すための道具箱（`Ctrl + Shift + D`）

## うごかす

```bash
bun install
bun run dev      # http://localhost:3000 でホットリロード付き起動
```

その他のコマンド:

```bash
bun run start      # ホットリロードなしで起動
bun run build      # dist/ に本番用バンドルを出力
bun run typecheck  # tsc --noEmit で型チェック
```

### 画面の行き来

遊びの土台は街並み画面。起動するといきなりそこから始まる。

```
   左上 🗺 地図 ────→ 地点を選ぶ ───┐
        │                            ↓
   ┌────┴───────────── 街並み画面 ←──┘
   │      ├─ 人物をクリック ──フェード──→ シナリオ会話画面 ──→ 街並みへ戻る
   │      ├─ ナゾをクリック ──フェード──→ ナゾ解き画面    ──→ 街並みへ戻る
   │      └─ 右下 👞 靴 → 三角の矢印 ──フェード──→ 隣の街並み
   │
   右上 🧳 メインメニュー
          ├ 進行状況／メモ／チャーム（タブ）
          └ 調査メモ／深まるナゾ／ナゾ事典／セーブ／設定
```

地図とメインメニューのアイコンは、画面の左上と右上に常に出ている
（`src/components/Hud.tsx`）。会話中とナゾ解き中だけは、邪魔にならないよう隠れる。

### はじまりと再開

- **最初から** — 街道の馬車止め（町の外）の街並みから始まる
- **続きから** — 最後にセーブした街並みと、その見渡していた位置から再開する
  （`GameState` の `streetId` / `streetX` に記録している）

### 街並み画面

カメラそのものがクロードたちの目線なので、画面に自分の姿は出ない。
奥・中・手前の 3 層を別々の速さで動かして、道を進んでいる感じを出している
（`src/components/StreetScene.tsx`）。手前の層は横幅 300% で、その中の座標が
そのまま「道の 0〜1」になる。

- **見渡す** — 画面下の ◀ ▶ を押しっぱなし、`←` `→` / `A` `D`、
  または画面を左右にドラッグ（指の動きと景色が 1 対 1 で動く）
- **入る** — 人やナゾをクリックすると、暗転（フェード）してその画面へ移る。
  画面中央に来ているものは下のボタンでも入れる（`Space` / `Enter`）
- 頭上の印は **！** が本筋、**？** が立ち話、**✓** が会話済み
- ナゾは時計・日時計・懐中時計の形で道端に置いてある
- **キラキラ**が光っていたらクリックする。収集アイテムを拾える（各街並みに 2 つ）

#### 隣へ歩く

画面の右下にある**靴**のアイコンを押すと移動モードに入り、道の先や曲がり角に
**三角の矢印**が出る。押すと暗転して、その方向の街並みへ移る。
矢印が画面の外にあるときは、押した拍子にカメラが一番近い矢印までなめらかに寄る。

- 矢印の向きは 4 種類（`ExitDir`）。奥へ ▲ ／ 手前へ ▼ ／ 左へ ◀ ／ 右へ ▶
- 矢印には行き先の名前が添えてある。まだ行けない場所は灰色で押せない
- もう一度靴を押すと矢印は引っこむ
- 出口は `src/data/streets.ts` の `exits` に書く。行き帰り両方を書いておくこと
  （片道しかないと `registry.ts` が起動時に知らせる）

### ナゾ解き画面

街並みに置かれた時計を押すと始まる、物語から独立した一問。全 10 問。
出題の形式をなるべく散らしてある。

| 形式 | 例 | 実装 |
| --- | --- | --- |
| 数値入力 | 鐘は何回鳴るか／鐘の鳴り終わり／重なる針 | `kind: 'number'` |
| 選択 | 鏡の時計／噛み合う歯車／止まった時計 | `kind: 'choice'` |
| 一問一答のなぞなぞ | 三つの足（言葉で答える。表記ゆれを吸収） | `kind: 'text'` |
| ウミガメのスープ | 丘の花（「はい／いいえ」を無料で開いてから選ぶ） | `clues` ＋ `kind: 'choice'` |
| 二次元パズル | 時計塔の灯り（4×4 のます目に、各行各列一つずつ） | `kind: 'grid'` |
| 並べかえ | あの夜の順番（押した順に番号がつく） | `kind: 'order'` |

- **ヒント** は一つにつき ひらめきコイン 1 枚
- 誤答するたびに得られるピカラットが下がる（例: 30 → 25 → 20）
- 正解すると **解説** が読め、以降ナゾ事典からも読み返せる
- 全問を一発で正解すると合計 365 ピカラット

### 収集アイテム

街のあちこちにキラキラが落ちている。クリックすると拾え、メインメニューの
**コレクション**に入る。全 12 個（各街並みに 2 つずつ）。

アイテム 1 つにつき、次を持たせている（`src/data/items.ts`）。

- **名前** — 一覧に並ぶ見出し
- **フレーバーテキスト** — その品にまつわる短い文。事件の周辺を補う内容にしてある
- **絵** — `ItemIcon` の種類。`src/components/ItemIcon.tsx` で SVG を描く

拾った側の記録（`GameState.collected`）には、**どの場所で拾ったか**と
**そのときのプレイ時間**も残す。コレクションの各項目を開くと両方読める。

### バックアップ

メインメニューの**バックアップ**から、進行状況を一本のテキストに書きだせる。

- **コードをコピー** — クリップボードへ
- **ファイルに保存** — `cookieclaude-backup-YYYYMMDD-hhmm.txt` として書きだす
- **このコードから復元** / **ファイルを選ぶ** — 貼りつけ、またはファイルから読みこむ

コードの形は `CC1.<本体>.<検算>`（`src/state/saveCode.ts`）。
本体は進行状況の JSON を base64url にしたもの、検算は写しまちがいを見つけるための
4 桁。改行や空白はどこに入っていてもよく、ファイルの全文を貼りつけても読める。
検算が合わない、版が違う、中身が壊れている場合は読みこまずに理由を出す。

### メインメニューの中身

道具（1 段目・2 段目）:

- **調査メモ** — 会話で手に入れた手がかりの一覧
- **深まるナゾ** — **物語全体**にかかわること。概要、本件の争点、進行度、
  読み進めるほど増える「判明していること」、関係者
- **ナゾ事典** — **独立したナゾ一問ずつ**の一覧。解いた問題は
  選ぶと解説を読み返せる
- **セーブ** — `localStorage` に保存
- **コレクション** — 街で拾った品の一覧
- **バックアップ** — 進行状況の書きだしと読みこみ
- **設定** — 画面の大きさ（小 560 / 中 720 / 大 880 / 特大 1040 / 全画面）、
  BGM と効果音のオンオフ・音量、画面エフェクトのオンオフ・強さ。
  セーブとは別に `localStorage` に残る
- **？？？** — 未開放スロット

タブ（下段）:

- **進行状況** — 解いたナゾ・ひらめき指数・ひらめきコイン・プレイ時間・現在地・進行度
- **メモ** — 自由記入のメモ帳
- **チャーム** — 集めたお守り
- **閉じる** — 直前の画面へ戻る

## エフェクト

Processing のようなインタラクティブアートを、あとから挿しこむための場所。
画像は使わず、canvas に手続きで描く。

### 差しこみ口

各画面に `<EffectLayer slot="..." />` が置いてある。この canvas は
親いっぱいに広がり、**クリックは通りぬける**ので、上に重ねても操作を邪魔しない。

| slot | 場所 |
| --- | --- |
| `street.back` | 街並み。空と建物の上、人やナゾより奥 |
| `street.front` | 街並み。何よりも手前 |
| `scenario.front` | 会話画面 |
| `puzzle.front` | ナゾ解き画面 |
| `menu.back` | メインメニュー。文字より奥 |
| `boot.front` | 表紙 |

いま入っているのは 3 つ。残りの口は空いていて、登録するだけで混ざる。

- **陽だまりの塵**（`street.back`）— 奥行きごとに追従量を変えてあり、
  道を見わたすと手前の粒ほど大きく流れる
- **メープルの落ち葉**（`street.front`）— 指を近づけると風を受けて押しのけられ、
  離すと元の落ちかたに戻る
- **星座**（`boot.front`）— 漂う点を近いものどうし線でつなぐ。指のほうへ寄ってくる

### 書きかた

Processing と同じ `setup` / `draw` の組み立て。持ちものは `create()` の中に閉じこめる。

```ts
export function createSomething(): EffectSketch {
  let things: Thing[] = [];
  return {
    // 大きさが決まったとき・変わったときに呼ばれる
    setup({ width, height }) { things = ...; },
    // 毎コマ呼ばれる。画面は消してあるので、描くだけでよい。
    draw({ ctx, width, height, time, dt, pointer, strength, cameraT }) { ... },
  };
}
```

`draw` に渡るもの:

| 名前 | 中身 |
| --- | --- |
| `ctx` | 2D の描画文脈。CSS ピクセルで描ける（`devicePixelRatio` は吸収ずみ） |
| `width` / `height` | 差しこみ口の大きさ |
| `time` / `dt` | 動きだしてからの秒数と、前のコマからの秒数（跳ねないよう頭打ちあり） |
| `pointer` | 画面の中の指の位置（0〜1）。触れていなければ `null` |
| `strength` | 0〜1。設定の「強さ」。濃さや数に掛ける |
| `cameraT` | 街並みのカメラ位置（0〜1）。ほかの画面では 0 |

**足しかた**

1. `src/effects/sketches/` にファイルを作り、`create???()` を書く
2. `src/effects/registry.ts` の `EFFECTS` に一行足す（`slot` で場所が決まる）

画面側に手を入れる必要はない。ひな型は開発者モードの「ひな型」から写せる。

全体のオンオフと強さはメインメニューの「設定」から。
端末が「動きを控える」設定のときは、はじめからオフで始まる。

## 開発者モード

中身（場所・人物・会話・ナゾ・アイテム・エフェクト）を後から足すための道具箱。
遊ぶ人には出さず、次のどちらかで入る。

- `Ctrl + Shift + D`
- URL に `?dev=1`（`?dev=0` で出る）

一度入るとこの端末では覚えておく。遊びの側とは切り離してあり、
`App` からは `<DevTools api={...} />` を一つ置いているだけ。

| 欄 | できること |
| --- | --- |
| **検査** | `registry.ts` の検査結果を画面で読む。各データの件数 |
| **中身へ飛ぶ** | 街並み・会話・ナゾへ直接飛ぶ。開放／読了／正解の入り切り |
| **配置** | 街並みをクリックして座標を読みとり、貼れる一行にする |
| **ひな型** | 会話・ナゾ・アイテム・人物・場所・エフェクトの骨組みを写す |
| **状態** | コインやピカラットの書きかえ、全開放、初期化、JSON の出し入れ |
| **エフェクト** | どの差しこみ口に何が入っているか。一つずつ入り切り |

### 座標ひろい

いちばん手間のかかる「0〜1 のどこに置くか」を、目分量で書かずに済ませるための道具。

1. 「配置」で **座標をひろう** を入れる（引き出しは閉じてよい）
2. 街並みの置きたいところをクリックする
3. 人／ナゾ／キラキラ／出口 を選ぶと、貼れる一行が出る

```
{ id: 'sk_clocktower_3', itemId: '???', x: 0.62, y: 0.55 },
```

**置き場所を見せる** を入れると、いま置いてあるものに目じるしと座標が出る。
既存の並びを見ながら、間を埋めるように置ける。

## ものがたり

メープル町に届いた差出人のない手紙 ——
「まちの時計が十三回鳴る夜、まちの宝が消える」。
探偵クロードと助手クッキーが、5 つの場所をめぐって町のナゾを解き明かす。

- 本筋 6 話 ＋ 町の人との立ち話 5 話
- 独立したナゾ 10 問・合計 365 ピカラット（すべて一発正解のとき）
- 収集アイテム 12 個
- 本筋を読み進めると、行ける場所が増えていく

## 中身を足す

場所・街並み・人物・会話・ナゾ・アイテムは、すべて `src/data/` の中だけで
完結している。id でつなぐだけなので、画面側に手を入れずに増やせる。

**書きまちがえは起動時に見つかる。** `src/data/registry.ts` が id のつながりを
通しで検査し、問題があればコンソールに並べる。見ているのは次のようなこと。

- 置き忘れたナゾ、話しかける人のいない会話、どこにも落ちていないアイテム
- 実在しない id への参照、id の重複、0〜1 の外にある座標
- 出口の行き先が実在するか、戻り道があるか、たどって行き着けるか
- 最初から開いている場所と、会話で開かれる場所の食いちがい
  （両方に書くと幕開けを飛ばせてしまい、どちらにも無い場所は永久に行けない）
- 答えの形の破綻（選択肢の外を指す正解、項目とかみ合わない並べかえ など）

中身を足したらブラウザのコンソールを一度見ること。
**開発者モード（`Ctrl + Shift + D`）の「検査」**でも同じものが読める。
座標を決めるのが面倒なときは、同じく開発者モードの「配置」を使う。

**会話を足す**

1. `src/data/scenarios.ts` に `Scenario` を追加（`kind` は `'main'` か `'flavor'`）
2. `src/data/streets.ts` の `npcs` に、その会話を持つ人を並べる
   （`x` は道の 0〜1。`requiresScenario` を書くと、その会話のあとに現れる）

`note` / `charm` / `unlocks` を書いておくと、読了時に調査メモ・チャーム・
新しい行き先が自動的に増える。本筋を足したときは `src/data/story.ts` の
`STORY_BEATS` にも一行足すと、深まるナゾに反映される。

**アイテムを足す**

1. `src/data/items.ts` の `ITEMS` に一つ追加（`name` / `flavor` / `icon`）
2. `src/data/streets.ts` の `sparkles` に落ちている場所を足す
   （`x` は道の 0〜1、`y` は画面の高さの 0〜1）
3. 新しい絵が要るときは `src/types.ts` の `ItemIcon` と
   `src/components/ItemIcon.tsx` に足す

**場所（ステージ）を足す**

1. `src/data/places.ts` に `Place` を追加（地図上の `x` / `y` と `streetId`）
2. `src/data/streets.ts` に対応する `Street` を追加
   （`npcs` / `puzzles` / `sparkles` は空でもよい）
3. 隣の街並みと `exits` でつなぐ。**行きと帰りの両方**を書く
   （`to` が行き先の `Street.id`、`dir` が矢印の向き、`x` / `y` が置き場所）
4. 背景を増やすなら `src/types.ts` の `BackgroundId` と、
   `src/components/StreetScene.tsx`・`src/components/Background.tsx` に足す
5. どこかの会話の `unlocks` に新しい場所の id を入れて、行けるようにする

**ナゾを足す**

1. `src/data/puzzles.ts` の `PUZZLES` に一問追加
   （`answer` は number / choice / text / order / grid のいずれか。
   `hints` と `explanation` は必須。ウミガメのスープにするなら `clues` も）
2. `src/data/streets.ts` の `puzzles` に、置き場（`x` と `look`）を足す
3. 新しい図が要るときは `src/types.ts` の `FigureId` と
   `src/components/PuzzleFigure.tsx` に足す

**エフェクトを足す**

1. `src/effects/sketches/` にファイルを作り、`create???(): EffectSketch` を書く
2. `src/effects/registry.ts` の `EFFECTS` に一行足す（`slot` で差しこむ場所が決まる）
3. 新しい差しこみ口が要るときは `src/types.ts` の `EffectSlot`、
   `src/effects/registry.ts` の `EFFECT_SLOTS`、そして置きたい画面に
   `<EffectLayer slot="..." />` を一つ足す
