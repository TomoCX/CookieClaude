# クッキーとクロードの謎解き事件簿

レイトン風のシナリオアドベンチャーアプリ。
町のマップから街並みに入り、道を歩いて人に話しかけ、マップの時計でナゾを解いていく。

- **ランタイム**: Bun
- **言語**: TypeScript
- **フレームワーク**: React 19
- **CSS**: 素の CSS（フレームワーク・プリプロセッサなし）
- **画像素材**: なし。背景・立ち絵・マップ・ナゾの図はすべてインライン SVG で描画

## うごかす

```bash
bun install
bun run dev      # http://localhost:3000 でホットリロード付き起動
```

その他のコマンド:

```bash
bun run start      # ホットリロードなしで起動
bun run build      # dist/ に本番用バンドルを出力
bun run typecheck  # tsc --noEmit で型チェック
```

## 画面構成

| 画面 | ファイル | 説明 |
| --- | --- | --- |
| メイン画面 | `src/screens/MainScreen.tsx` | 町のマップ。行き先ピンと、ナゾの時計が並ぶ |
| 街並み画面 | `src/screens/StreetScreen.tsx` | 道を左右に歩ける。立っている人をクリックすると会話へ |
| シナリオ会話画面 | `src/screens/ScenarioScreen.tsx` | 立ち絵つきの会話。日本語＋英字幕 |
| ナゾ解き画面 | `src/screens/PuzzleScreen.tsx` | ストーリーから独立した 1 問。図・ヒント・かいせつつき |
| メニュー画面 | `src/screens/MenuScreen.tsx` | とけたナゾ・ひらめきしすう・プレイじかん等のステータス |
| メインメニュー | `src/screens/MainMenuScreen.tsx` | トランク型の道具ばこ |

### 画面の行き来

```
                        メイン画面（マップ）
                                │
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
   行き先ピン              時計を押す              右上 ⚙ / 右下 🧳
        ↓                       ↓                       ↓
   街並み画面 ──人をクリック──→ ナゾ解き画面      メニュー画面／メインメニュー
        │      ↑                  │
        │      └── 会話が終わると 街並みへ戻る
        ↓
   シナリオ会話画面
```

メイン画面の右上・右下のボタンは、写真3枚目の指定どおりの配置。街並み画面にも
同じ位置に置いてあるので、探索中でもそのまま行き来できる。

### 街並み画面

奥・中・手前の 3 層を別々の速さで動かして、道を進んでいる感じを出している
（`src/components/StreetScene.tsx`）。手前の層は横幅 300% で、その中の座標が
そのまま「道の 0〜1」になる。

- **歩く** — 画面下の ◀ ▶ を押しっぱなし、または `←` `→` / `A` `D`
- **話す** — 人を直接クリックすると、その人の手前まで歩いてから会話が始まる。
  近くにいるときは下の「〇〇に 話しかける」ボタンでも話せる（`Space` / `Enter`）
- 頭の上のしるしは **！** が本筋、**？** が立ち話、**✓** が会話ずみ

### ナゾ解き画面

マップに置かれた時計を押すと始まる、ストーリーから独立した 1 問。

- こたえは数値入力か選択式
- **ヒント** は 1 つにつき ひらめきコイン 1 まい
- まちがえるともらえるピカラットが下がる（例: 30 → 25 → 20）
- 正解すると **かいせつ** が読め、以降ナゾじてんからも読み返せる

### メインメニューの中身

- **ちょうさメモ** — 会話で手に入れた手がかりの一覧
- **ふかまるナゾ** — **ストーリー全体**にかかわること。あらすじ、事件の問い、
  進行度、読み進めるほど増える「わかっていること」、出会った人
- **ナゾじてん** — **独立したナゾ解き 1 問ずつ**の一覧。といた問題は
  タップするとかいせつを読み返せる
- **セーブ** — `localStorage` に保存
- **？？？ ×3** — 未開放スロット
- **メモ** — 自由記入のメモ帳
- **チャーム** — 集めたお守り
- **とじる** — 直前の画面へ戻る

## 操作

| 画面 | 操作 | 結果 |
| --- | --- | --- |
| 街並み | `←` `→` / `A` `D` | 道を歩く |
| 街並み | `Space` / `Enter` | 近くの人に話しかける |
| 街並み | `Esc` | マップへ戻る |
| 会話 | クリック / `Space` / `Enter` | 会話を進める（表示途中なら全文表示） |
| 会話 | `Esc` | 中断して街並みへ戻る |
| ナゾ | `Enter` | こたえる（数値入力のとき） |

## ものがたり

メープル町に届いた差出人のない手紙 ——
「まちの時計が十三回鳴る夜、まちの宝が消える」。
探偵クロードと助手クッキーが、5 つの場所をめぐって町のナゾを解き明かす。

- 本筋 5 話 ＋ 町の人との立ち話 5 話
- 独立したナゾ 6 問・合計 195 ピカラット（すべて一発正解のとき）
- 本筋を読み進めると、行ける場所とマップに現れる時計が増えていく

## 中身を足す

**会話を足す**

1. `src/data/scenarios.ts` に `Scenario` を追加（`kind` は `'main'` か `'flavor'`）
2. `src/data/streets.ts` の `npcs` に、その会話を持つ人を並べる
   （`x` は道の 0〜1。`requiresScenario` を書くと、その会話のあとに現れる）

`note` / `charm` / `unlocks` を書いておくと、読了時にちょうさメモ・チャーム・
新しい行き先が自動的に増える。本筋を足したときは `src/data/story.ts` の
`STORY_BEATS` にも 1 行足すと、ふかまるナゾに反映される。

**ナゾを足す**

1. `src/data/puzzles.ts` の `PUZZLES` に 1 問追加
   （`answer` は数値か選択式、`hints` と `explanation` は必須）
2. 同じファイルの `PUZZLE_SPOTS` にマップ上の置き場を足す
   （`requiresCleared` で、本筋を何話読むと現れるかを決める）
3. 新しい図が要るときは `src/types.ts` の `FigureId` と
   `src/components/PuzzleFigure.tsx` に足す
